# Security policy

## Supported version

This repository is a portfolio edition rather than a supported production service. Security reports should refer to the latest commit on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability or exposed credential. Contact the maintainer privately through [LinkedIn](https://www.linkedin.com/in/shabar-naderi-1b7623b2/) and include the affected component, reproduction steps and potential impact.

Do not include real credentials, personal information or third-party data in a report.

## Deployment note

The example environment files contain placeholders only. Anyone evaluating the project locally must generate fresh secrets and must not reuse the development configuration in production.
